# BEYIM Calculator 🧮

A clean, modern web calculator built with single-file HTML, CSS, and JavaScript, featuring a sleek glassmorphic UI and a custom expression parsing engine[cite: 1].

## ✨ Features
* **Glassmorphism Design**: Modern card layout with responsive grid styling and mobile safe-area support[cite: 1].
* **Theme Toggle**: Switch smoothly between a deep dark mode and a crisp light mode[cite: 1].
* **Advanced Parsing**: Handles standard arithmetic, parentheses, percentages, and negative numbers using a custom-built parser[cite: 1].
* **Keyboard Friendly**: Type naturally with your keyboard (`Enter` to calculate, `Backspace` to delete, `Escape` to clear)[cite: 1].

## 🚀 Quick Start
1. Clone or download the repository.
2. Open `index.html` in any web browser. No installation or build steps required!

## 🛠️ Built With
* **HTML5**[cite: 1]
* **CSS3** (Grid, CSS Variables, Backdrop Filters)[cite: 1]
* **Vanilla JavaScript** (Custom Tokenizer & Parser)[cite: 1]
